# 案例：《小石潭记》

本案例独立验证新模板，不是新课文的固定结构。学习目标是从鱼、水、石和竹树中寻找证据，解释感受如何由乐转为凄清。场景里设置“水中的鱼”“潭底与石岸”“环合的竹树”三个观察点；每个点都有对应的局部图、原文、问题和解读。实际教学时请按所用教材核对文字。

| 热点 | 全景中应看到 | 点开后的局部图 | 原文焦点 |
| --- | --- | --- | --- |
| 水中的鱼 | 画面中央偏下的游鱼 | `fish.png`：清水、游鱼和鱼影 | “空游无所依” |
| 潭底与石岸 | 画面右侧的近岸岩石与水下石底 | `stone.png`：石底和露出水面的石岸 | “全石以为底”“卷石底以出” |
| 环合的竹树 | 画面左侧的竹丛与树木 | `bamboo.png`：竹树围绕小潭 | “四面竹树环合” |

这张对应表是制作检查，不是让后续课文复用这三个点。点位须以实际全景里看见的对象为准；图片或点位不符就修改。
