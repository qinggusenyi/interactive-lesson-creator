## 全景原理与限制

`setupGL()`（源码约 95 行）创建 WebGL1 全屏四边形；fragment shader 根据 yaw/pitch/fov 算视线，经 atan/asin 得纹理坐标。`loadTexture()` 加载内嵌图片。`draw()` 限设备像素比至 1.5，`scheduleDraw()` 用 requestAnimationFrame 合并更新。

指针拖动改变 yaw/pitch，yaw 用 `wrap()` 循环，pitch 限 ±50°；滚轮 FOV 48～95°。是**固定观察点环视**，没有几何场景、自由行走、景深遮挡、头显 VR 或物体背面数据。`drawHotspots()` 把图片百分比映射到方位/俯仰后用正切近似投影 DOM；不应把此近似直接宣称为在任意俯仰都精确贴合。

四张样片为 1774×887，虽是 2:1，不保证严格等距柱状投影。`seamless_panorama.py` 在左右 8% 区域混合减缝；这不等于真正无缝，也不消除重复物体和投影失真。

## 热点、教学和动画

`showHotspot()` 把原文短句、局部图、解释和提问组成卡片，并用 `animateView()` 的 smoothstep 转向。学生模式暂藏一段解释，点击揭晓；教师模式用于对比解读。`showTourPanel()` 自动导览直接展示解释，因此原版“教师模式”不等于所有页面都严格隐藏答案，重用时须修正。

`openMicro()` 有七类局部互动：翻砖揭晓、听合成提示找虫、四图辨果、蚂蚁观察、课堂合成提示音、canvas 描画、雪地动作流程。`birdStep()` 用 CSS 状态、SVG 鸟、定时器形成等待/拉绳反馈。它们与原文感官、动作、儿童兴趣结合，并非一般教学都应照搬的游戏。

声音由 Web Audio oscillator 合成，不是虫声采样、历史课堂录音，也没有单词 TTS、麦克风、自动批改或联网聊天。

## 视觉经验与应改进点

有效：大场景作主体；深绿背景与暖金高亮；衬线标题和无衬线正文分层；局部特写帮助从全景回到细读；短转向而非持续炫动；固定首页背景；支持 prefers-reduced-motion。

不足：许多正文/按钮为 11～14px，投影偏小；body 最小宽度 900px；侧栏叠在场景上会遮住热点；全景失败主要提示文字而非完整替代阅读路径；弹窗未提供完整焦点约束。新模板使用较大正文、分栏卡片、原生 dialog、阅读列表降级。

## 依赖与素材边界

运行时：浏览器 WebGL、DOM、Canvas2D、Web Audio、Fullscreen；无 npm 框架、CDN、后端、外部模型 API。系统字体 Microsoft YaHei UI/PingFang/serif，没有随包分发字体文件。

制作：Python 标准库负责内嵌；图片整理脚本另用 Pillow/Numpy。验证：Node vm 桩测试；部分截图脚本通过 Edge CDP + websockets。源码检查通过不等于真实浏览器通过。旧 `使用说明.md` 声称不能 file://，后期规划又记有截图，存在文档时序差异；本仓库验证记录重新执行并区分结果。

原项目课文依据：人教社刊载鲁迅文本，见 examples 的来源清单。生成图引用私有生成目录，缺统一公开再分发授权；全部排除。截图、成片、ZIP、用户路径、浏览器配置也排除。新仓库不复制旧代码正文，按观察到的模式重写最小通用实现。

可复用：需求到交互映射、数据驱动场景、图文证据链、分层揭晓、短动效、离线内嵌、浏览器验证流程。专有：课文摘句、场景布局、人物传说、捕鸟流程、具体热点方位、原图及裁切映射。
