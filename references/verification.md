# 验证清单

`python scripts/verify.py <index.html>` 检查打包、内嵌资源、数据结构与 JavaScript 语法；它不能证明浏览器交互和视觉效果。

把输出 HTML 单独复制到空文件夹，用 Chrome 或 Edge `file://` 打开，离线操作：

1. 查看封面、地图、场景，确认画面完整，无外链和控制台错误。
2. 点击每个热点，确认热点所在的全景位置真有对应物体，独立局部插画画了同一对象或动作；随后逐一核对原文、问题和解读。不能用同一张泛景图充当多个热点的局部图；若不对应，调整点位或重做图后再交付。学生模式默认隐藏解读。
3. 试显示解读、教师模式、关闭、返回、下一处和重置。
4. 拖动、键盘转向、滚轮缩放、跨 ±180°；确认热点始终贴在对应物体上，接缝可接受。
5. 检查 1366×768、1920×1080 和窄窗口；看文字、按钮、卡片是否遮挡或溢出；检查减弱动效与无 WebGL 的文字入口。
6. 把图片与原文逐一对照，确认教学推断来自文字而非插画臆造。记录摘句版本和素材来源。

无法执行浏览器测试时，交付记录应如实写“静态通过，浏览器交互未验证”。不能把脚本 PASS 或截图当成交互验收。
