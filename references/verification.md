# 验证与诚实报告

## 静态检查

`python scripts/verify.py path/to/index.html` 检查：HTML 容器、内嵌数据、资源不外链、占位符、脚本语法（有 Node 时）、图像/音频可解码格式头、数据字段和资源个数。**通过不代表交互已经执行**。无 Node 时脚本语法标 SKIP。

## 浏览器最小闭环

把 HTML 单独复制到空文件夹，用 Chrome/Edge `file://` 打开；离线或拦截所有网络请求。不要靠特殊允许本地读取的启动参数掩盖缺资源。

1. 首页/任务可读，场景完整；图像加载成功，无控制台错误、远端请求。
2. 点击每个热点，对应短句正确；学生模式没有默认解读；回答选择题看两种反馈；显示解读后内容确实改变。
3. 证据归类/笔记输入、加入证据板、关闭和返回、重置均可用。开放解释不自动判唯一对错。
4. 切换所有场景；试缩放、拖动和键盘；热点仍贴图。导览上一/下一可控，不自动扫过答案。
5. 切教师模式，旧卡和新卡行为一致；有音频则真实播放/停止并检查错误提示。
6. 1920×1080 和 1366×768 检查任务、主要文字、按钮无遮挡；笔记长文本可滚动；小窗口不横向溢出；Tab/Enter/Esc 可操作；减弱动效生效。
7. 全景模式另检纹理加载、±180° 连续转向、俯仰/缩放、热点投影；禁用 WebGL 仍能从列表读卡。

自动化可用现有浏览器工具或 `tests/browser-check.cjs`（需开发端安装 puppeteer-core，并指定 Chrome/Edge）。不要求课堂电脑装测试依赖。无浏览器能力则交付“静态通过、运行未验证”，不能制造 PASS。

## 内容、素材和授权

记录摘句版本与来源，原文/改写/解读分开。数学、物种、历史、人物情感避免从插画推出事实。逐素材列来源与授权状态，不把“网上找的”“AI 生成”自动当作可公开分发。

## 测试记录格式

记录日期、Agent/模型环境、触发方式（显式/自动/未测）、真实输入、教学决策、输出文件、执行命令、浏览器版本、尺寸、点击断言、截图、失败与修复、待人工核对。无独立对照实验时不能声称 Skill 比普通提示词“提升 X%”；可以记录明确产物差异，以及哪些差异尚未验证因果。
