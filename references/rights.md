# 许可证建议与素材检查

## 本仓库范围

建议并采用 MIT 许可于**本仓库新编写的 Skill 文档、脚本和模板**。这不为课文作者、出版社页面、第三方音色或用户提供素材授予许可。《小石潭记》样例的四张新生成插画说明见 [../examples/ASSET-NOTICE.md](../examples/ASSET-NOTICE.md)。

例子仅包含必要的少量课文短句与来源链接，没有收录全文、教材扫描、网站图片或朗读音频。使用者应按所在地法律、教材版本和实际传播范围核查引用条件；不对跨地区公版状态作统一保证。

## 原项目排除清单

| 排除项 | 原因 / 处理 |
|---|---|
| 四张全景图及其他生成原图 | 缺逐素材公开再分发授权记录；不复制 |
| 果实/自然/故事图集、蚂蚁/雪地/鸟群图 | 同上；生成与形态准确性不等于版权核验 |
| 旧单文件 HTML、分享 ZIP | 内嵌上述图片/课文；不直接重新发布 |
| 项目截图、视频、真人形象 | 不属于可复用模板，涉及个人素材 |
| 浏览器 profile、私有生成目录、绝对本机路径 | 可能带用户数据，排除 |
| 课文全文、出版社页面图片/录音 | 独立第三方内容，不并入 MIT |
| 系统字体文件 | 仅 CSS 字体回退；不分发字体二进制 |
| 旧项目代码原件 | 未发现明确的原项目独立许可；观察设计模式后新写通用实现 |

## 新课件发布前逐项填写

`文件 / 创作者或来源URL / 取得日期 / 允许课堂使用 / 允许公开再分发 / 署名要求 / 仍待确认`。

若授权未知，保留本地私用版本并在公开包排除，改用原创示意或经许可的素材。不要只改扩展名或 base64 内嵌来规避授权。音频工具开源许可证与服务输出使用条款分别核对。
