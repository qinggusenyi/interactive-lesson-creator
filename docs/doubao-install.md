# 豆包工作安装与验收

## 当前可确认与未确认

豆包官方开放平台公开介绍了Skill接入能力：<https://open.doubao.com/>（核查2026-10-18）。公开首页未提供本次可核实的完整客户端导入规格、API安装命令或稳定目录约定。

因此下文是**按客户端实际入口操作的安装说明**；本次没有操作豆包客户端验证，不能称“已在豆包成功安装”。不要凭本说明写入猜测的隐藏目录、绕过权限或宣称只传ZIP就一定自动安装。

## 导入步骤

1. 下载 `interactive-lesson-creator.zip`，解压检查：只有一个同名技能文件夹，里面直接是 `SKILL.md` 和配套目录。
2. 在豆包**工作任务**中打开技能管理。若当前版本有“添加/上传技能/导入”入口，按其支持类型选ZIP或解压后的文件夹。保留references、assets、scripts目录，不要只传SKILL.md。
3. 导入后在技能列表核对名称 `interactive-lesson-creator` 和“语文环视互动课件”描述。若当前账号/版本没有导入入口，先停止安装；可以把完整文件夹作为任务附件并要求读取，但应称“按附件执行”，不算安装。
4. 若支持从对话安装，可附ZIP并说“请把附件作为自定义技能安装；若你只能读取附件，请说明未安装”。只有技能列表中出现并可选用，才算完成导入。

## 第一次使用的完整指令

> 请使用 interactive-lesson-creator。先阅读SKILL.md及环视实施参考。我要给七年级做《春》的10分钟互动课件，学生要环视草地和花树、比较词语，并写两条原文证据。不要复制百草园章节。用可用工具创建文学环视素材，缺工具时明确告诉我缺什么，不能换成普通平移图片。运行时不联网，最后交付单独一个index.html；样式、脚本、图片、所需音频全部内嵌。先生成和运行，再报告哪些操作已真实测试、哪些未测试。

## 如何确认它真的用上Skill

- 宿主若展示技能调用记录，查看是否加载本技能；否则要求列明实际读取的SKILL.md和参考文件，注意这只是辅助证据。
- 看是否先建立“目标—操作—学习产物—依据”，而非直接输出整页动画。
- 成品能独立双击离线运行、环视而不是拖一张平面图、热点与视角一致、解读先隐藏、练习反馈有理由。
- 要求原始执行结果或截图，不能只接受Agent口头“验证通过”。

## 工具条件

豆包需能读附件、写文件，最好能执行Python和操作浏览器；若没有Python，可直接生成内联HTML，但仍需浏览器验证。只有图片输入能力而没有生成能力时，需要你提供全景图或另行生成。TTS不是必需能力；英语点读时再使用edge-tts制作本地MP3。

## 安装包与老师课件是两回事

- Skill ZIP给Agent安装，包含方法、模板、打包器。
- `index.html`给老师使用，单独一个文件即可。
- 老师不用安装Skill、Python、edge-tts或申请API Key。

界面更新时以当前客户端说明为准。若导入拒绝该结构，保留错误原文再调整包结构，不把未经验证的替代方案记成成功。
