# 豆包工作导入说明

下载本仓库，按客户端支持的 Skill 导入入口导入整个目录，确认 `SKILL.md` 与 `assets/`、`scripts/`、`references/` 同级。不同客户端的入口可能不同，不能把“附件已读取”当作“Skill 已安装”。

示例请求：

> 使用 interactive-lesson-creator，根据我提供的语文课文和教学目标做一个单文件离线互动课件。请自行分析适合观察的细节、决定热点位置、制作与热点对应的局部图、核对原文，并按照封面、探索地图、全景场景和细节卡的节奏完成。逐点检查图文对应，真实测试后再交付；没能运行的检查请明确说明。

构建脚本需要制作端有 Python 3.9+。如果当前客户端不能运行代码或制作图片，应说明缺口，不宣称已生成可用成品。
