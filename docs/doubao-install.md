# 豆包工作导入说明

豆包工作支持导入本地技能文件。下载本仓库并导入整个 `interactive-lesson-creator` 文件夹，或导入本项目制作的 `interactive-lesson-creator-doubao.zip`。压缩包内应有同名顶层文件夹，其下 `SKILL.md` 与 `assets/`、`scripts/`、`references/` 同级。官方入口通常在「技能・连接器・伙伴」的自建技能区域；具体按钮以当前客户端为准。不能把“附件已读取”当作“Skill 已安装”。

示例请求：

> 使用 interactive-lesson-creator，根据我提供的语文课文和教学目标做一个单文件离线互动课件。请自行分析适合观察的细节、决定热点位置、制作与热点对应的局部图、核对原文，并按照封面、探索地图、全景场景和细节卡的节奏完成。逐点检查图文对应，真实测试后再交付；没能运行的检查请明确说明。

构建脚本需要制作端有 Python 3.9+，且需有生成或准备全景图、局部图的能力。导入后先用一篇新的课文做验收：让豆包生成 `index.html`，独立打开，逐一检查全景、三个不同位置的热点、图片与原文是否对应。`examples/xiaoshitan` 是范例，不是让新课文替换标题后复用。若当前客户端不能执行脚本或制作图片，应说明缺口，不宣称已生成可用成品。

参考：[飞书官方关于豆包工作自建与导入技能的说明](https://www.feishu.cn/content/article/7677519271848610746)、[豆包工作伙伴技能说明](https://aily.feishu.cn/hc/1u7kleqg_zja0qy5v)。
